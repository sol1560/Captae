# Linux AppImage 里随带的系统库

由 `scripts/gen-appimage-libs.sh` 生成（不要手改）。AppImage 要在不同的发行版上直接运行，打包时 linuxdeploy 和它的 GTK 插件
把下面这些库和辅助程序从打包机器（Ubuntu 22.04.5 LTS）拷进了 AppImage，原样、没有改动，都是动态链接。随带哪些看打包机器上装了什么，
表里是几台打包机器打的 AppImage 合起来的（发版的包不一定每个都带）；「版本」是生成这份清单的机器上装的版本，发版的打包机器上可能差一个小版本（同一个 Ubuntu 发行版）。
.deb 不带这些，用系统自己的。

AppImage 的启动部分不在表里：开头的 runtime 和根目录的 AppRun / AppRun.wrapped 来自 AppImage 项目（MIT，
https://github.com/AppImage/type2-runtime 、https://github.com/AppImage/AppImageKit ，Tauri 打包时下载的构建）。

源码：每个包对应的 Ubuntu 源码包（表里「源码」一列的链接，或在 Ubuntu 上 `apt-get source <源码包>=<版本>`）。
LGPL 的库可以换成用户自己编译的版本：把同名的 .so 放进解开的 AppImage（`--appimage-extract`）的 `usr/lib/` 即可。
各包的版权声明和许可证原文（Debian 的 copyright 文件，及其中引用的 LGPL / GPL 全文）见 `linux-appimage-copyright.txt`。
